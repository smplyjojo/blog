# Blog da Jojo

Blog pessoal para compartilhar imagens, fotos e textos, com espaço para comentários.

## Como usar

Abra o arquivo `index.html` em um navegador. Escreva um texto ou escolha uma imagem e clique em **Publicar**. Para comentar, escreva no campo abaixo da publicação.

As publicações e os comentários ficam salvos no armazenamento local do navegador (`localStorage`). Eles aparecem novamente quando o blog é aberto no mesmo navegador, mas não são enviados para a internet nem compartilhados com outras pessoas. Para isso, seria necessário conectar o projeto a um servidor e a um banco de dados.
